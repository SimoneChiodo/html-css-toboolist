# Progetto HTML-CSS: Toboolist

### Descrizione

Questo progetto rappresenta una semplice **web app di gestione attività (to-do list)**, realizzata con HTML e CSS. 

## Caratteristiche principali

- **Header**: include un logo e il titolo "Toboolist", posizionati in modo orizzontale con allineamento verticale centrato.
- **Sezione pulsanti**: due pulsanti per aggiungere nuove attività ("Add Task") e nuove sezioni ("Add Section"), posti in cima alla pagina.
- **Lista delle attività organizzata in sezioni**:  
  - Ogni sezione ha un titolo espandibile (es. "New Task", "Today", "Upcoming") con sotto una serie di task.  
  - Ogni task mostra uno stato tramite un'icona (✓ o ✗) colorata in verde o rosso.  
  - Accanto ai task sono visualizzate delle etichette colorate (tag) che indicano la categoria o priorità (es. Editorial, Q1 Goals, Recruiting).

## Aspetto grafico

- Layout pulito e moderno con uso di sfondo chiaro e card bianche arrotondate.
- Font Roboto per leggibilità.
- Colori vivaci per bottoni, etichette e stati dei task per una chiara distinzione visiva.
